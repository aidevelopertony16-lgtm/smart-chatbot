# 🤖 Smart Chatbot | الشات بوت الذكي

An intelligent conversational AI that remembers chat history, built using Python and Google's Gemini AI API. 
شات بوت ذكي يتذكر سجل المحادثة، مبني باستخدام لغة بايثون ونموذج جيميناي من جوجل.

## 🚀 Features | المميزات
* **Context Aware:** Remembers previous messages in the conversation. (يتذكر الرسائل السابقة في المحادثة).
* **Fallback Protection:** Automatically switches to a stable AI model if the main one is busy. (حماية تلقائية ضد ضغط الخوادم).
* **Secure:** Uses environment variables to protect API keys. (يستخدم متغيرات بيئة لحماية المفاتيح).

## 🛠️ Tech Stack | التقنيات المستخدمة
* Python
* Google Colab
* Gemini API (Google GenAI)
